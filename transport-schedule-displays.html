Overview

Project Overview

E-paper driven displays powered by Raspberry Pi and custom firmware deliver real-time schedule information to hundreds of commuters daily.

The project covered the USB driver integration, a wireless provisioning system, and a double-buffer image delivery pipeline, pushing what embedded Linux and e-paper technology can do in a real-world transit environment. Built with the team at C3 Labs, including Kasun.

Key Components & Features

USB Driver Integration

Driver integration for the e-paper panels on the Raspberry Pi.

Wireless Provisioning

A provisioning system for setting up deployed displays wirelessly.

Double-Buffer Image Pipeline

Seamless image delivery so the display updates cleanly with real-time schedule data.
