Elevator Control Using PLC

Overview

Project Overview

An elevator control system built around a Siemens S-400 PLC that manages all operations: responding to floor requests, moving the cabin, opening and closing doors, and ensuring passenger safety.

Push buttons, floor sensors and door switches are monitored by the PLC, which drives outputs such as motors and relays for smooth, efficient movement. Automating these decisions improves reliability and safety by reducing human error. The ladder program was written in Simatic Manager.
